# FH6 テレメトリ ウィジェット仕様

## 概要
配信画面にオーバーレイできる、常に最前面表示の軽量テレメトリウィジェット。
Electron でフレームレス・背景透過のウィンドウとして実装する。

## 表示項目

### Car Info (上部、1行)
- **Class**: D / C / B / A / S1 / S2 / S2+ / X
- **PI**: 100〜999
- **駆動方式**: FWD / RWD / AWD

### Input (メイン表示)
- **ステアリング**: 中央基準の左右バー (-127〜127)
- **アクセル**: 縦バー (0〜255)、緑
- **ブレーキ**: 縦バー (0〜255)、赤
- **ハンドブレーキ**: インジケーター (OFF=白丸 / ON=赤丸)

## レイアウト案

```
┌──────────────────────────────┐
│  B 650  AWD          [─] [×]│  ← Car Info + ウィンドウ操作
├──────────────────────────────┤
│                              │
│  ◄████████████|░░░░░░░░░►   │  ← ステアリングバー (横)
│                              │
│   ██  ░░                     │
│   ██  ░░            ○ HB    │  ← アクセル(緑),ブレーキ(赤) 縦バー + HB
│   ██  ░░                     │
│   ██  ░░                     │
│   A   B                      │
└──────────────────────────────┘
```

## ウィンドウ仕様
- **サイズ**: デフォルト 320×300px、リサイズ可
- **常に最前面**: alwaysOnTop = true
- **フレームレス**: frame = false
- **背景透過**: transparent = true (半透明ダーク背景はHTML/CSSで描画)
- **ドラッグ移動**: タイトルバー領域に `-webkit-app-region: drag` を設定
- **閉じるボタン**: 右上に最小化・閉じるボタン (no-drag領域)

## 技術構成
- `widget.js` — Electron メインプロセス。UDP受信 + パケットデコード + IPC送信
- `widget-preload.js` — contextBridge で telemetry データをレンダラーに公開
- `widget.html` — ウィジェットUI (CSS/JS埋め込み)

## データフロー
```
FH6 (UDP 34598) → widget.js (dgram) → IPC → widget.html (描画)
```
- 16ms間隔 (60fps) でレンダラーに送信
- web.js (Webダッシュボード) とはポートが競合するため同時起動不可
  → 同時に使いたい場合は将来的に web.js 経由の WebSocket 接続に切り替え可能

## 起動コマンド
```
npx electron widget.js
```
または package.json に:
```json
"widget": "electron widget.js"
```
