# FH6 テレメトリ ウィジェット仕様

## 概要
配信画面にオーバーレイできる、常に最前面表示の軽量テレメトリウィジェット。
Electron でフレームレス・背景透過のウィンドウとして実装する。

## 表示項目

### Car Info (タイトルバー)
- **Class**: D / C / B / A / S1 / S2 / R / X (色付きバッジ)
- **PI**: 100〜999
- **駆動方式**: FWD / RWD / AWD

### Input (メイン表示)
- **ステアリング**: 中央基準の左右バー (-127〜127)
- **アクセル**: 縦バー (0〜255)、緑
- **ブレーキ**: 縦バー (0〜255)、赤
- **クラッチ**: インジケーター (OFF=空心丸 / ON=青丸)
- **ハンドブレーキ**: インジケーター (OFF=空心丸 / ON=赤丸)

## ウィンドウ仕様
- **サイズ**: デフォルト 300×280px、リサイズ可。最小サイズ 160×120px (これ未満はウィンドウ側で抑止)。アクセル/ブレーキの縦バーを含む各UIはウィンドウ幅・高さに応じて縦横に伸縮する (固定幅・固定高さは持たない)。コンテンツが収まらない場合はメイン領域・設定パネルとも縦スクロール可 (スクロールバーは 6px の細表示)。
- **常に最前面**: alwaysOnTop = true (設定でOFF可)
- **フレームレス**: frame = false
- **背景透過**: transparent = true (透明度調整可 / 完全透明モード)
- **ドラッグ移動**: タイトルバー領域に `-webkit-app-region: drag`
- **最小化/閉じる**: ウィンドウ下部のボトムバーに配置
- **サイズ・位置記憶**: リサイズ/移動時に自動保存、次回起動で復元
- **画面外チェック**: 保存位置がモニタ外の場合はOS既定位置にフォールバック
- **シングルインスタンス**: 2つ目の起動は既存ウィンドウをフォーカス

## 設定画面 (ダブルクリックで開閉)
- **背景を完全透明**: チェックボックス (透明度スライダーと排他)
- **背景透明度**: スライダー 10〜100%
- **常に最前面**: チェックボックス
- **メニュー時/停止時に自動非表示**: チェックボックス (デフォルトOFF)
  - 以下のいずれかの状態が「非表示までの秒数」継続したら、フェードアウトで画面を隠す:
    - **メニュー状態**: `IsRaceOn !== 1` (メニュー、ポーズ、リプレイ、リワインド、ゴール後)
    - **停止状態**: `IsRaceOn === 1` (走行扱い) でも、以下を**すべて**満たす場合:
      - アクセル入力 = 0 (`Accel == 0`)
      - ブレーキ入力 = 0 (`Brake == 0`)
      - ステアリング中央 (`|Steer| ≦ 5`、`STOP_STEER_THRESHOLD`)
      - 車速が停止判定の閾値内 (`|Speed| ≦ 0.5 m/s`、`STOP_SPEED_THRESHOLD`。オフセット 256 の `Speed` float をデコード)
      - 水平加速度が停止判定の閾値内 (`hypot(AccelerationX, AccelerationZ) ≦ 0.5 m/s²`、`STOP_ACC_THRESHOLD`。オフセット 20/28 の F32 をデコード)
    - 加速度の Y 軸 (`AccelerationY`) は車両ローカル座標で重力成分を常に含むため判定からは除外する。X (右) と Z (前) のみを用い、「操作はしていないが車が動き出している/外力で動かされている」状態でも非表示にしないようにする。
  - **隠してはいけないシナリオ (表示維持)** ‐ 上記条件が満たされず、停止判定が false になることで保証される:
    - 坂道を下っている最中無操作: 車速 > 0.5 m/s で false
    - ジャンプ台ジャンプ中 (上昇/下降) 無操作: 水平方向の運動量が保存されるため通常 Speed > 0.5 で false (ほぼ真上の跳躍など、Speed が水平成分のみの場合に頂点で誤判定する理論的可能性はあるが FH6 の通常プレイでは発生しない)
    - NPC や他プレイヤーに押されている: 押された瞬間に `hypot(AccX, AccZ) > 0.5` で false、動き始めれば Speed > 0.5 で false
  - 上記いずれかの条件解除 (操作再開・走行再開) で即座にフェードイン復帰する。
  - 設定パネルが開いている間は非表示にしない (開いた瞬間に保留中の hideTimer もクリアされ、即座に表示が戻る)。
  - **テレメトリ未接続時は autohide を発火しない**: 直近の UDP パケット受信から `STALE_MS` (= 500ms) 以上経過している場合は「FH6 が起動していない / 接続先 IP・ポートが違う / FW で止まっている」とみなし、走行/停止/メニューの判定に関わらず常に表示維持する。タイトルバー右端の `#waiting` 領域には `No telemetry` と表示する。フェード状態に入っていた場合も即座に解除。UDPが一度も来ていない初期状態 (renderer に `onTelemetry` が一度も来ない) でも、autohide スケジュールが立たないため同じく表示維持。
- **非表示までの秒数**: スライダー 1〜10秒 (デフォルト3秒)。メニュー判定・停止判定の両方で共通使用。
- **Port**: UDP受信ポート (デフォルト34598)
- **IP Address**: 「IP指定」ボタンで入力欄表示 (デフォルト127.0.0.1)

設定は `%APPDATA%/fh6-telemetry-widget/widget-settings.json` に自動保存。

## 技術構成
- `widget.js` — Electron メインプロセス。UDP受信 + パケットデコード + IPC送信
- `widget-preload.js` — contextBridge でテレメトリ/設定/ウィンドウ操作APIを公開
- `widget.html` — ウィジェットUI (CSS/JS埋め込み、CSP設定済み)

## データフロー
```
FH6 (UDP 34598) → widget.js (dgram) → IPC (16ms) → widget.html (描画)
```

## セキュリティ
- `contextIsolation: true`, `nodeIntegration: false`
- `win-setting` IPC はホワイトリスト方式でキーを制限
- `loadSettings` はスキーマバリデーション付き
- CSP でスクリプト/スタイルのソースを制限
- UDP エラーハンドリング実装済み

## 起動コマンド
```
pnpm widget
```
ビルド:
```
pnpm build
```
